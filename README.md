# مزايد سيارات

منصة عربية RTL لبيع ومزايدة السيارات. تحافظ النسخة المطورة على الهوية الكحلية والبرتقالية وواجهة الجوال، وتستبدل المحتوى الثابت بطبقات بيانات ومصادقة وصلاحيات حقيقية.

## ما تم تنفيذه

| المجال | التنفيذ |
| --- | --- |
| المصادقة والصلاحيات | مصادقة OAuth مدمجة بجلسة HTTP آمنة، وأدوار `user` و`admin`، وحالة حساب `active` أو `suspended` تُتحقق خادميًا. |
| الإعلانات | مسودة، مراجعة، نشر، رفض، أرشفة، وتحقيق دلالي في المتصفح والخادم. |
| المزادات | سعر بداية، زيادة دنيا، وقت بداية ونهاية، حالة خادمية، سجل مزايدات، ومنع المزايدة الذاتية أو المنخفضة. |
| البحث | بحث نصي، فلترة بالشركة والمدينة ونوع الإعلان، فرز وترقيم. |
| المستخدم | ملف شخصي، إعلانات المستخدم، مفضلة، رسائل، ووثائق توثيق. |
| الإدارة | مراجعة الإعلانات والوثائق، تعليق أو تنشيط الحسابات، إحصاءات وسجل عمليات. |
| التخزين | الصور والوثائق ترفع إلى S3 عبر `storagePut`، مع حفظ المفتاح والرابط والبيانات الوصفية فقط في قاعدة البيانات. |
| الإشعارات | إشعارات داخل التطبيق عند المزايدة والرسائل واعتماد أو رفض الإعلان والوثائق، مع معالج آمن لتنبيهات قرب انتهاء المزادات. |

## التشغيل المحلي

```bash
pnpm install
pnpm dev
```

تُحقن متغيرات البيئة الخاصة بالمصادقة وقاعدة البيانات والتخزين تلقائيًا من بيئة المشروع. لا تُنشئ أو ترفع ملف `.env` يحتوي أسرارًا.

## مخطط البيانات والترحيلات

تُعرّف الجداول في `drizzle/schema.ts` وتشمل المستخدمين، الإعلانات، الصور، الوثائق، المزادات، المزايدات، المفضلة، المحادثات، الرسائل، الإشعارات وسجل العمليات.

عند أي تغيير في المخطط:

```bash
pnpm drizzle-kit generate
```

راجِع ملف SQL المولد أولًا، ثم طبقه بواسطة أداة إدارة قاعدة البيانات المعتمدة للمشروع. لا تستعمل عمليات حذف أو تعديلات مدمرة دون نسخة احتياطية وخطة ترحيل صريحة.

## الاختبارات والتحقق

```bash
pnpm check
pnpm test
```

تغطي الاختبارات الحالية تسجيل الخروج وقواعد التحقق الأساسية للإعلانات والمزادات. ينبغي إضافة اختبارات إجراءات الخادم لكل ميزة جديدة، خصوصًا حول التفويض، التزامن في المزايدات، والملكية.

## دور المشرف

يُمنح مالك المشروع دور `admin` تلقائيًا عند أول تسجيل دخول. يمكن للمشرف فتح `/admin` لمراجعة الإعلانات والوثائق وإدارة المستخدمين. لا تمنح صلاحية الإدارة من الواجهة؛ عدّل الدور من قاعدة البيانات أو من أدوات إدارة المشروع فقط.

## تنبيه قرب انتهاء المزاد

يوجد معالج idempotent في `POST /api/scheduled/auction-reminders`. لا يعتمد التطبيق على `setInterval` أو مؤقتات الذاكرة. بعد إنشاء نقطة حفظ ونشر الموقع، أنشئ مهمة Heartbeat على مستوى المشروع لاستدعاء هذا المسار كل خمس دقائق، وفق سياسة التحديثات الدورية في المشروع. لا تُنشأ المهمة من بيئة التطوير لأن الرابط العام للإنتاج مطلوب.

## حدود النسخة الحالية

الإشعارات منفذة داخل التطبيق. لم يُربط مزود بريد خارجي، لأن ذلك يحتاج موفر بريد وبيانات اعتماد موثقة. كما أن بدء مهمة Heartbeat الفعلية يتطلب نشر الموقع أولًا ثم إعدادها على بيئة الإنتاج.
